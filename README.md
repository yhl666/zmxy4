**名称：** 造梦西游4 道具列表搜索工具

**引言：** 请确保你已经在电脑上安装了以下软件：

*   "vscode编译器"
*   "MySQL 8.0.36 Community Server - GPL版本"
*   "node.js v-20.12.0版本"

1.  以上所有步骤做好之后，打开 `select.js` 文件，点击右上角运行按钮。
2.  打开浏览器，访问 `http://localhost:3000`，您应该能够看到搜索表单并进行查询。
